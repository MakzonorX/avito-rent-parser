# Парсер аренды квартир · Тюмень

Следит за новыми объявлениями об аренде квартир на Avito и присылает подходящие
в Telegram — с фотографиями, параметрами и ссылкой. Управление через веб-админку.

Форк [Duff89/parser_avito](https://github.com/Duff89/parser_avito): движок парсинга оттуда,
сверху добавлены веб-интерфейс с мастером настройки, фильтры по параметрам квартиры
и карточки объявлений в Telegram. Документация исходного проекта — в [docs/README.upstream.md](docs/README.upstream.md).

---

## ⚠️ Главное: нужен российский IP

Avito пускает только российские IP-адреса. С зарубежного сервера или через VPN все
запросы возвращают блокировку (`403`/`439`), и парсер работать не будет.

Поэтому сервер берите российский — Yandex Cloud, VK Cloud, Selectel, Timeweb, Beget.
Мастер настройки в админке проверит доступ и прямо скажет, пускает Avito или нет.

## Запуск на новом сервере (docker compose)

Всё, что нужно на сервере — docker. Занимает 10–15 минут.

### 1. Установить docker

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
```

Перелогиньтесь (`exit` и зайдите заново), чтобы docker заработал без `sudo`.

### 2. Скачать проект

```bash
git clone https://github.com/MakzonorX/avito-rent-parser.git
cd avito-rent-parser
```

Репозиторий приватный — git спросит логин и пароль. В качестве пароля нужен
[personal access token](https://github.com/settings/tokens) с правом `repo`
(обычный пароль от GitHub не подойдёт). Либо настройте доступ по SSH-ключу и клонируйте
через `git@github.com:MakzonorX/avito-rent-parser.git`.

### 3. Собрать и запустить

```bash
docker compose up -d --build
```

Первая сборка идёт 5–10 минут: качается Python, зависимости и Chromium.
Дальше контейнер поднимается за секунды и стартует сам после перезагрузки сервера.

Проверить, что поднялся:

```bash
docker compose ps
docker compose logs -f
```

### 4. Открыть админку

Порт наружу намеренно не открыт — админка без пароля, и выставлять её в интернет нельзя.
Пробросьте порт по SSH **со своего компьютера**:

```bash
ssh -L 9999:localhost:9999 user@адрес-сервера
```

Не закрывая это окно, откройте в браузере **http://localhost:9999**

### 5. Пройти мастер настройки

При первом входе сам откроется мастер и проведёт по шагам:

1. **Telegram-бот** — создать бота у [@BotFather](https://t.me/BotFather) (`/newbot`), вставить токен,
   узнать свой chat_id у [@userinfobot](https://t.me/userinfobot), **написать боту любое сообщение**
   (без этого он не сможет вам ответить) и нажать «Проверить связь» — придёт тестовое сообщение.
2. **Доступ к Avito** — кнопка «Проверить доступ» покажет ваш IP, страну и ответ Avito.
   Если блокирует — там же можно вписать российский прокси и проверить снова.
3. **Что искать** — ссылка на поиск, цена, комнатность, частота проверки.
4. **Запуск** — кнопка «Запустить парсер».

Первый запуск проходит молча: парсер запоминает объявления, которые уже висят на Avito,
чтобы не завалить чат полусотней сообщений. В Telegram придут только новые.

Мастер можно открыть заново кнопкой 🧭 в шапке.

## Telegram с российского сервера

С российских IP `api.telegram.org` недоступен — запросы просто уходят в таймаут.
Парсер при этом работает: объявления находятся и видны в админке, но уведомления не уходят.
Нужен зарубежный выход **только для трафика к Telegram** (сам Avito, наоборот, требует российский IP).

Два способа, оба сводятся к одному полю в настройках.

### Способ 1. Свой зарубежный сервер (бесплатно)

Если есть любой сервер за границей с доступом по SSH — скрипт поднимет до него
постоянный SOCKS5-туннель:

```bash
sudo ./scripts/telegram-tunnel.sh user@адрес-зарубежного-сервера
```

Скрипт проверит, нужен ли туннель вообще, поставит autossh, настроит вход по ключу,
создаст systemd-сервис (поднимается сам после перезагрузки) и напечатает строку,
которую надо вставить в поле «Прокси для Telegram» — обычно `socks5://172.17.0.1:1080`.

### Способ 2. Зарубежный SOCKS5-прокси (быстрее, платно)

Купите **зарубежный** прокси (российский не подойдёт — Telegram недоступен и с него)
и вставьте в админке → Настройки → Telegram → «Прокси для Telegram»:

```
socks5://user:pass@ip:port
```

Затем «Отправить тестовое сообщение». Формат распознаётся автоматически,
для SOCKS5 схема `socks5://` обязательна.

> Прокси нужен только для отправки уведомлений. Фотографии Telegram скачивает
> с Avito сам, со своей стороны — через прокси они не идут.

## Управление контейнером

```bash
docker compose logs -f          # смотреть логи
docker compose restart          # перезапустить
docker compose down             # остановить
docker compose up -d --build    # обновить после git pull
```

Настройки, cookies, найденные объявления и логи лежат в папке `data/` рядом с проектом
и переживают пересборку контейнера. Бэкап — обычная копия этой папки:

```bash
tar czf backup.tar.gz data/
```

## Запуск без docker (например, на ноутбуке)

```bash
./start.sh
```

Первый запуск сам создаст окружение и поставит зависимости. Затем откройте http://localhost:9999

Вручную:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python run_web.py
```

## Что настраивается в админке

| Раздел | Параметры |
|---|---|
| Что отслеживаем | ссылки на поиск Avito, страниц на ссылку, пауза между проверками, «не старше N часов» |
| Параметры квартиры | цена от/до, комнатность, площадь, этаж (в т.ч. «не первый», «не последний») |
| Адрес и слова | нужные и исключаемые районы/улицы, обязательные слова и стоп-слова |
| Telegram | токен, получатели, количество фото, прокси для TG, режим «только текст» |
| Доступ к Avito | прокси, таймауты, повторы, cookies |

**Своя ссылка.** Настройте поиск на avito.ru как нужно (район, тип жилья, комнатность)
и вставьте адрес из строки браузера. Важно включить сортировку **«по дате»** — иначе новые
объявления не попадут на первую страницу. В ссылке это `&s=104`.

## Если Avito блокирует

Проверить доступ можно кнопкой в мастере (🧭 в шапке) — она покажет IP и ответ Avito.

1. **IP не российский** — самая частая причина. Нужен сервер или прокси из России.
2. **IP российский, но блокирует** — так бывает с серверными адресами. В разделе
   «Доступ к Avito» нажмите «Получить автоматически»: откроется headless-браузер,
   заберёт cookie `ft`, и запросы начнут проходить. Не помогло — откройте avito.ru
   в своём браузере, скопируйте cookies (DevTools → Application → Cookies или
   `document.cookie` в консоли) и вставьте вручную там же.
3. **Прокси не пропускает к Avito** — проверка покажет это отдельной формулировкой.
   Многие продавцы прокси держат Avito в чёрном списке: прокси исправно ходит на любые
   сайты, но на `avito.ru` отвечает `403 Forbidden` на CONNECT (или SOCKS5 reply 2).
   Это не ошибка настройки — спросите у поддержки, разрешён ли Avito на тарифе,
   или берите прокси, где это прямо заявлено. На российском сервере прокси обычно не нужен.
4. **Совсем никак** — мобильный прокси. Подробности в [docs/ANTIBLOCK.md](docs/ANTIBLOCK.md).

Формат прокси распознаётся автоматически (`user:pass@ip:port`, `ip:port@user:pass`,
через двоеточия). Для SOCKS5 добавьте схему: `socks5://user:pass@ip:port`.

## Как это работает

```
Ссылка Avito ──> spfa.ru ──> URL мобильного API ──> запрос (curl_cffi + cookies)
                                                          │
                        ┌─────────────────────────────────┘
                        ▼
   фильтры: цена, свежесть, стоп-слова, комнатность, площадь, этаж, адрес
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  Telegram (альбом фото             SQLite: показанные
   + параметры + ссылка)            объявления не повторяются
```

Проверка идёт по кругу с паузой из настроек (по умолчанию 5 минут). Показанные объявления
запоминаются и повторно не приходят; если у объявления изменилась цена, оно придёт снова.

Ссылка Avito превращается в адрес мобильного API через сторонний сервис
[spfa.ru](https://spfa.ru) — бесплатно, не чаще 2 запросов в минуту, результат кешируется
в `data/storage/avito_api_urls.json`, так что для одной ссылки это делается один раз.
