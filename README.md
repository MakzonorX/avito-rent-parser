# Парсер аренды квартир · Тюмень

Отслеживает новые объявления об аренде квартир на Avito и присылает их в Telegram —
с фотографиями, параметрами и ссылкой. Управление через веб-интерфейс на `localhost:9999`.

Форк [Duff89/parser_avito](https://github.com/Duff89/parser_avito): движок парсинга взят оттуда,
добавлены веб-админка, фильтры по параметрам квартиры и карточки объявлений в Telegram.
Документация исходного проекта — в [docs/README.upstream.md](docs/README.upstream.md).

## Запуск

```bash
./start.sh
```

Первый запуск сам создаст окружение и поставит зависимости (3–5 минут).
Дальше открывай **http://localhost:9999** — все настройки там, править файлы руками не нужно.

Вручную:
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python run_web.py
```

## ⚠️ Главное условие: российский IP

Avito пускает только российские IP-адреса. Через VPN или зарубежный сервер все запросы
возвращают блокировку (`403`/`439`), и парсер работать не будет — это видно на дашборде
как «Все запросы к Avito блокируются».

Варианты:
1. **Отключить VPN** для avito.ru (в клиенте VPN добавить `avito.ru` и `*.avito.st` в обход/direct).
   Домашний российский интернет-адрес подходит лучше всего.
2. **Указать российский прокси** в разделе «Доступ к Avito».

Если и с российским IP приходят блокировки — нажми **«Получить автоматически»** в разделе
Cookies: откроется браузер, заберёт cookie `ft` и парсер начнёт ходить с ней.
Не сработало — открой avito.ru в своём браузере, скопируй cookies
(DevTools → Application → Cookies, либо `document.cookie` в консоли) и вставь их вручную.

## Настройка Telegram

1. Создай бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. Узнай свой chat_id у [@userinfobot](https://t.me/userinfobot).
3. **Напиши своему боту любое сообщение** — иначе он не сможет тебе писать.
4. Вставь токен и chat_id в настройки, нажми «Отправить тестовое сообщение».

Получателей может быть несколько — по одному chat_id в строке.
Чтобы слать в группу, добавь бота в неё и укажи id группы (начинается с `-100`).

## Что можно настроить

| Раздел | Параметры |
|---|---|
| Что отслеживаем | ссылки на поиск Avito, страниц на ссылку, пауза между проверками, «не старше N часов» |
| Параметры квартиры | цена от/до, комнатность, площадь, этаж (в т.ч. «не первый», «не последний») |
| Адрес и слова | нужные и исключаемые районы/улицы, обязательные слова и стоп-слова |
| Telegram | токен, получатели, количество фото, прокси для TG, режим «только текст» |
| Доступ к Avito | прокси, таймауты, повторы, cookies |

**Своя ссылка.** Настрой поиск на avito.ru как тебе нужно (район, тип жилья, комнатность)
и вставь адрес из строки браузера. Важно: включи сортировку **«по дате»** — иначе новые
объявления не попадут на первую страницу. В ссылке это `&s=104`.

**Первый запуск молча** — при первом старте парсер запоминает всё, что уже висит на Avito,
и не шлёт эти объявления пачкой. В Telegram пойдут только те, что появятся дальше.

## Как это работает

```
Ссылка Avito ──> spfa.ru ──> URL мобильного API ──> запрос (curl_cffi + cookies)
                                                          │
                        ┌─────────────────────────────────┘
                        ▼
   фильтры: цена, свежесть, стоп-слова, комнатность, площадь, этаж, адрес
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  Telegram (альбом фото             SQLite: показанные
   + параметры + ссылка)            объявления не повторяются
```

Проверка идёт по кругу с паузой `pause_general` (по умолчанию 5 минут).
Уже показанные объявления запоминаются в `database.db`, повторно не приходят;
если у объявления изменилась цена, оно придёт снова.

## Запуск на сервере

Сервер должен быть **российским** (иначе см. раздел про IP).

```bash
.venv/bin/python run_web.py --public   # админка будет доступна извне, порт 9999
```

Открывать порт 9999 наружу без авторизации не стоит — лучше пробросить его по SSH:

```bash
ssh -L 9999:localhost:9999 user@server
```

Чтобы парсер работал постоянно — systemd-юнит:

```ini
[Unit]
Description=Avito rent parser
After=network.target

[Service]
WorkingDirectory=/path/to/parser_avito
ExecStart=/path/to/parser_avito/.venv/bin/python run_web.py
Restart=always
User=youruser

[Install]
WantedBy=multi-user.target
```

Парсер стартует остановленным — после запуска сервиса нажми «Запустить» в веб-интерфейсе.
